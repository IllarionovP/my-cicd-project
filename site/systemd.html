⚙️ Модуль 3: Системные службы и Безопасность

Перевод бегунка (Runner) в режим фонового демона под управлением операционной системы Fedora.

Системные юниты (System Units)

Наш робот прописался по пути /etc/systemd/system/. Теперь он автоматически запускается при старте виртуалки, даже если никто не залогинен в систему.

Борьба с SELinux

В Fedora встроенная система безопасности блокировала запуск службы из папки /home/sasuke/, так как это нарушает корпоративные стандарты изоляции. Мы решили это через временное отключение setenforce 0 и смену контекста безопасности chcon.

Команды управления:

# Проверить статус робота-бегунка
sudo systemctl status actions.runner.*

# Остановить службу деплоя
sudo systemctl stop actions.runner.*

# Запустить службу обратно
sudo systemctl start actions.runner.*
