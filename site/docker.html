📦 Модуль 1: Контейнеризация и Docker

На этом этапе мы упаковали наш сайт в изолированную "коробку" — Docker-образ.

Ключевые инсайты:

  • Команда COPY index.html /usr/share/nginx/html/ копирует файлы не на Fedora, а во внутреннюю изолированную структуру самого образа.
  • На самом хосте Fedora веб-сервер Nginx не установлен, система остается чистой.

Полезные команды:

# Ручная сборка образа
sudo docker build -t my-app:v1 .

# Запуск контейнера на порту 8080
sudo docker run -d -p 8080:80 --name my-web-container my-app:v1

# Проверка запущенных контейнеров
sudo docker ps -a
