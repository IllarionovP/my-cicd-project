🔄 Модуль 2: Автоматизация CI/CD

Мы связали репозиторий GitHub, облачную сборку GitHub Actions, склад Docker Hub и наш сервер в единый конвейер.

Архитектурная схема (Pull-модель):

Код (Fedora) -> Push -> GitHub (Сборка образа) -> Push -> Docker Hub (Склад)
                               |
                        Сигнал по рации
                               v
                       Self-Hosted Runner -> Pull образа -> Запуск на Fedora

Зачем нужны были Secrets?

Мы скрыли DOCKERHUB_USERNAME и DOCKERHUB_TOKEN в секретах репозитория, чтобы облачный робот мог безопасно авторизоваться на Docker Hub и загрузить наш собранный образ, не раскрывая пароли всему интернету.
